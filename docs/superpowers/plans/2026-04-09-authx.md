# Authx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a TypeScript-based `authx` CLI plus a thin local Codex plugin wrapper for initializing, listing, saving, and switching Codex auth profiles under `~/.codex/authx/`.

**Architecture:** Keep all behavior in a small core library that works against injected filesystem roots so it is easy to test with temporary directories. Put command parsing and terminal output in a CLI layer, then add a thin plugin wrapper that shells out to the CLI so Codex `/authx` behavior stays aligned with terminal behavior.

**Tech Stack:** Node.js, TypeScript, Vitest, tsx
