---
description: "Manage local Codex auth profiles with authx"
---

Run the local `authx` CLI from the repository root.

- If the user invoked `/authx` with no extra arguments, run: `npm run authx`
- If the user invoked `/authx ...`, run: `npm run authx -- $ARGUMENTS`

Return the command result concisely. Do not reimplement profile logic in the prompt.
